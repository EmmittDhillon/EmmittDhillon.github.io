# My Knowledge OS

A starter personal knowledge-management website.

## Included
- Dashboard
- Medicine
- Finance
- Career
- Projects
- Knowledge
- Life
- Resources
- Inbox
- Search
- Dark mode
- Responsive mobile layout
- Starter note/project/resource dialogs

## Run locally
Open `index.html` in a browser.

## Free hosting
A simple next step is GitHub Pages. Upload these files to a GitHub repository and enable Pages from the repository settings.

## Important
Do not put patient-identifiable information or PHI in this system.
